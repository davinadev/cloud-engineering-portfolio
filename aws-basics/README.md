# AWS Basics

This repository documents my AWS learning journey through KodeKloud's hands-on cloud labs.

## Topics Covered

* Amazon EC2
* Amazon S3
* Amazon VPC

## Learning Method

All exercises are completed through KodeKloud's practical, hands-on labs. Each lab includes documentation, notes, screenshots, and key takeaways to reinforce real-world cloud engineering skills.

Build a strong foundation in AWS and cloud infrastructure while developing the practical skills needed for a Cloud Engineer career.
