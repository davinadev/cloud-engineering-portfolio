# Day 1 - Create Key Pair

## Date

May 28, 2026

## Goal

Learn how AWS Key Pairs work and create a key pair for secure access to EC2 instances.

## What I Did

* Logged into the AWS Management Console
* Navigated to the EC2 service
* Opened the Key Pairs section
* Created a new key pair
* Downloaded the private key (.pem file)
* Stored the key securely on my computer

## What I Learned

* AWS Key Pairs are used to securely connect to EC2 instances
* The private key (.pem file) should never be shared publicly
* If a private key is lost, it cannot be downloaded again from AWS
* Key Pairs are commonly used for SSH access to Linux EC2 instances

* Learning where Key Pairs are located within the EC2 console
* Understanding the difference between public and private keys
