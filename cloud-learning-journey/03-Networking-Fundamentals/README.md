## 🧠 Key Concepts

### Switch vs. Router

**Switch**

* Connects devices within a local network
* Primarily uses MAC addresses to forward Ethernet frames

**Router**

* Connects different networks
* Uses IP addresses to forward packets toward their destinations

### IP Address vs. MAC Address

**IP Address:** A logical address used to identify network destinations and route traffic.

**MAC Address:** An identifier associated with a network interface and used for local network communication.

### DNS

DNS translates human-readable domain names into IP addresses.

```text
example.com
     ↓
    DNS
     ↓
IP Address
     ↓
Web Server
```
